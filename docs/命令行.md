# 命令行方案（CLI）

> 不想用图形界面时，或要**批量**处理多个实验时，用这里的方式。
> 图形界面（双击 `启动psyweb工具.cmd`）适合一次性转换；命令行适合脚本化与可复现。

---

## 0. 前置条件

| 需要 | 说明 |
|---|---|
| **Node.js** | ≥ 18（用了内置 `fetch`）。装 LTS 版即可 |
| **PsychoPy** | Windows standalone 安装包即可（**它自带 Python**，无需另装）。实测（PsychoPy 官方 standalone 安装包）= Python 3.10.11 + psychopy 2026.2.3，解释器 `python.exe` 就在安装目录下 |
| 依赖库 | 首次运行前执行一次 `pwsh -File scripts/fetch-vendor.ps1` 与 `npm install` |

> 没装 PsychoPy 也能用：走 §4 的「已导出 js 兜底」路径。

---

## 1. 一条命令：`.psyexp` → 单文件便携包

```powershell
node src/build-portable.js `
     --psyexp "D:\实验\选择实验\untitled.psyexp" `
     --out    "D:\实验\选择实验\便携包.html" `
     --title  "选择实验"
```

**内部做了两件事**（都不需要你手工干预）：

```
① 官方 headless 编译器  psychopy.scripts.psyexpCompile
     untitled.psyexp → index.html + untitled.js + untitled-legacy-browsers.js
② psyweb 打包器
     修自动翻译缺陷 → 内联运行时与资源 → 装开始页/资源门禁/数据出口 → 单文件
```

实测输出（本机）：

```
① 官方编译器
   python : <PsychoPy安装目录>\python.exe
   psychopy: 2026.2.3
   耗时 2.2s → untitled.js, untitled-legacy-browsers.js, index.html
② psyweb 打包器
✅ 便携包已生成   大小: 3.60 MB
   实验脚本: 43 KB → 修复 2 处 → 补丁 4 处
   资源内联: 图片条件.xlsx / 三角形条件.xlsx / ima1.png / ima2.png / default.png(远端→占位)
```

### 参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `--psyexp <文件>` | ✅ | 输入的 `.psyexp` |
| `--out <文件>` | ✅ | 输出的单文件 html |
| `--title "名称"` | | 显示在**开始页**上的实验标题（被试看到的就是它） |
| `--expname <name>` | | 实验内部名（默认取 `.psyexp` 文件名），影响生成的文件名 |
| `--python <路径>` | | 指定 PsychoPy 自带的 python；也可用环境变量 `PSYWEB_PSYCHOPY_PYTHON` |
| `--autotest` | | 打包一个**自测版**：打开时加 `?autotest=1` 会自动模拟按键并导出数据（用于验证，不要发给被试） |

> **资源是自动收的**：打包器会解析 `.psyexp` 里引用的图片/音频/条件文件，**并读进条件文件内容**去找里面出现的媒体文件名（这是官方 Export HTML 的"自动探测"在做的事）。只扫 `.psyexp` 文本会漏掉 `ima1.png` 这类"名字写在条件表里"的资源。

## 2. 批量处理多个实验

```powershell
Get-ChildItem "D:\实验" -Recurse -Filter *.psyexp | ForEach-Object {
    $out = Join-Path $_.DirectoryName ($_.BaseName + "_便携包.html")
    Write-Host "→ $($_.Name)"
    node src/build-portable.js --psyexp $_.FullName --out $out --title $_.BaseName
}
```

## 3. 先体检，再转换（推荐）

转换前先看这个实验**能不能上网、要改哪几处**（不需要 PsychoPy）：

```powershell
node src/psyexp-audit.js "D:\实验\选择实验\untitled.psyexp" --md "体检单.md"
```

输出三级结论：🔴 阻断 / 🟡 需改造 / 🟢 可直上，并逐条给出位置、原因与建议动作。
也可以对整个目录批量跑：

```powershell
node src/psyexp-audit.js "D:\实验" --quiet --json "基线.json"
```

## 4. 兜底路径：只有已导出的 js / 没有 PsychoPy

如果你（或合作者）已经在 PsychoPy Builder 里点过 **Export HTML**，就不用装任何东西：

```powershell
node src/pack-portable.js `
     --dir "D:\实验\选择实验" `
     --js  "D:\实验\选择实验\untitled-legacy-browsers.js" `
     --psyexp "D:\实验\选择实验\untitled.psyexp" `
     --out "D:\实验\选择实验\便携包.html" `
     --title "选择实验"
```

- `--dir` 是资源所在目录（图片/条件文件），**必须给**，否则资源找不到。
- `--psyexp` 用于补全资源清单，**强烈建议给**（理由见 §1 的注）。
- 若导出目录里缺 `lib/`（常见），打包器会用仓库里锁定的官方运行时，不影响。

## 5. 转换后怎么用

| 步骤 | 对象 | 做什么 |
|---|---|---|
| 1 | 主试 | 把生成的 html **发给被试**（微信/QQ/邮件；提醒对方**在电脑上**打开，手机做不了） |
| 2 | 被试 | 双击 html → 开始页（知情同意）→ 点开始 → 做完 |
| 3 | 被试 | 结果页三选一回传：**结果摘要截图** / **下载 CSV** / **2 张数据二维码截图**（微信请勾"原图"） |
| 4 | 主试 | 双击 `site/collector.html`，把截图**拖进去** → 自动还原成 CSV → 合并多人 → 导出 |

## 6. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `找不到装了 PsychoPy 的 Python` | 用 `--python` 指定；或确认 PsychoPy 装在 `<盘符>:\PsychoPy\python.exe` |
| `补丁未命中: …` | 生成代码结构变了。**打包器会拒绝出包**（宁可失败也不产出坏包）；把提示发我，改补丁 |
| 官方检查器报 `Alert 4210 / Unexpected token` | PsychoPy 自动翻译出了非法 JS（典型：Code Component 里的 `import`）。打包器会自动修**可自动修**的那部分；修不了的会列在产物报告的"需人工确认"里 |
| 产物发给被试后白屏 | 让对方换较新的 Chrome/Edge（实验需要 WebGL）；开始页会显示 WebGL 检测结果 |
| 条件文件是 `.xlsx` | **不需要转 CSV**：psychojs 2026 内置解析（csv/odp/xls/xlsx 都支持） |

## 7. 产物与依赖的可复现性

- 第三方运行时库**不入库**，按 `vendor.lock.json`（URL + SHA256）拉取：
  ```powershell
  pwsh -File scripts/fetch-vendor.ps1 -VerifyOnly   # 校验；实测 ok=23 失败=0
  ```
- 打包器有**补丁后自检**（资源改道 / 开始页 / 数据导出 / 流程门禁 / 实验起始调用），少一条就拒绝出包。
