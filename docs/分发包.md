# 分发包（把工具交给别人）

> 目标：让别人**不装 Node、不配环境**，解压双击就能把 `.psyexp` 转成单文件便携实验包。

---

## 1. 为什么是"本地工具包"而不是在线服务

| 方案 | 为什么不选 |
|---|---|
| 在线网站（上传实验 → 云端转换） | 要把别人的实验文件与刺激材料传到你的服务器；还要背服务器、备案、数据出境。**而本工具的全部价值恰恰是"数据不出本机"** |
| 微信小程序 | 手机没有物理键盘，多数认知实验根本做不了；且小程序请求仍要求已备案域名 —— 省不掉服务器 |
| 让每人自己装 Node + 拉仓库 | 门槛太高，实际推广不下去 |
| **免安装工具包（本方案）** | 解压即用；全程本机；不需要账号、不需要备案 |

---

## 2. 包里有什么（实测体积）

| 内容 | 体积 | 说明 |
|---|---|---|
| `node\node.exe` | **87.4 MB** | 内嵌 Node.js，对方无需安装 |
| `src\*.js` | 0.10 MB | 转换器全部代码（含打包器、体检器、shim） |
| `spike\m0\vendor\` | 5.5 MB | 第三方运行时（PsychoJS 等），版本由 `vendor.lock.json` 锁定 |
| `node_modules\` | 1.78 MB | 运行期依赖（fast-xml-parser、qrcode-generator） |
| `tools\collector.html` | 0.3 MB | 成品的数据回收器（主试端） |
| `启动psyweb工具.cmd` / `使用说明.md` / `首次使用.txt` | 少量 | 入口与说明 |
| **合计** | **约 95 MB（zip 后约 36 MB）** | 微信/网盘都能发 |

> `spike\m0\vendor` 这个目录名是开发期留下的结构（打包器按此相对路径读运行时库），对使用者无影响。

## 3. 怎么构建分发包

```powershell
# 在仓库根目录
pwsh -File src/make-dist.ps1
# 可用参数：
#   -NodeExe "D:\node\node.exe"   指定要内嵌的 node.exe
#   -SkipZip                      只生成目录，不压缩
```

产出：
- `dist\psyweb-工具包\`（目录）
- `dist\psyweb-工具包.zip`（压缩包，直接发人）

脚本会做五件事：内嵌 node → 拷转换端代码 → 拷第三方运行时（按 lock）→ 拷运行期 npm 依赖 → 拷入口/回收器/说明，最后附上第三方许可证。
`dist/` 已在 `.gitignore` 中（构建产物不入库）。

---

## 4. 对方拿到包之后

1. 解压
2. 双击 **`启动psyweb工具.cmd`** → 浏览器自动打开本地工具页
3. 把**整个实验文件夹**拖进去（或点「选择文件夹」）→ 点「开始转换」
4. 产物落在包的 `输出\` 目录，页面上也给下载链接

工具页顶部会显示环境状态：找到 PsychoPy 就显示版本；没找到会给出两条可操作路径。

---

## 5. 关于 PsychoPy（必须说清的一点）

**包内不内嵌 PsychoPy** —— 实测 PsychoPy standalone 装完 **1,520 MB**，内嵌不现实；而且**目标用户本来就有**（能画出 `.psyexp` 的人必然装了 PsychoPy）。

对方机器上确实没有 PsychoPy 时，两条路：

| 路径 | 操作 | 需要 Python 吗 |
|---|---|---|
| ① 装 PsychoPy | 官网下载 standalone 版（自带 Python），装完重开工具 | 装完后需要，但用户无需自己配 Python |
| ② **兜底路径** | 让对方（或在任何一台有 PsychoPy 的机器上）在 Builder 里点一次 **Export HTML**，再把导出的文件夹交给本工具 | **不需要** |

兜底路径命令（工具页也写明了）：

```powershell
node src\pack-portable.js --dir <实验目录> --js <导出目录>\xxx-legacy-browsers.js --out <输出.html> --title "实验名称"
```

## 6. 许可证与合规

- 包内附 **`node\LICENSE.txt`**（Node.js 的 MIT 许可证原文，含其捆绑依赖的声明）。
- 包内附 **`第三方许可.md`**：逐个列出第三方组件的来源与 SHA256 指纹（由 `src/make-dist.ps1` 依据 `vendor.lock.json` 自动生成）。
- **本清单不代替许可证原文**。若要把本工具**公开分发**，请先补齐清单中各组件的许可证原文。
- 本工具自身代码的许可：**待定**（见仓库 `docs/决策记录.md` 的待决事项）。

## 7. 已知边界

- 仅 **Windows**（启动器是 `.cmd`，内嵌的是 Windows 版 node.exe）。要支持 macOS/Linux，需另做启动脚本——代码本身是跨平台的。
- 分发包**不含**示范实验数据；对方需要自己的 `.psyexp`。
- 首次启动会在本机 `127.0.0.1:7788` 起一个本地服务；**不监听外网**，也不发起任何外部请求（转换全部在本机完成）。
