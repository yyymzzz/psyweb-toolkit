# psyweb 使用说明

> 两个文件，一个闭环：
> **被试端** `portable_我的实验.html`（发出去）→ **主试端** `collector.html`（收回来）。
> 全程不需要服务器、不需要备案、不联网上传。

---

## 一、主试：怎么把实验发出去

1. 拿到**被试端单文件**（例：`portable_我的实验.html`，约 3.6 MB）。
2. 通过微信 / QQ / 邮件发给被试。**手机上别点开**（本实验需要键盘鼠标，手机无法完成）。
3. 告诉被试一句话即可：

> 「下载这个 html 文件，**在电脑上双击打开**，按提示点开始做完就行。做完会显示一个页面，**把那两张二维码截图发我**，或者点『下载数据文件』把 CSV 发我。微信发二维码请勾选**原图**。」

### 发给谁 / 发多少
- 单文件可以**发给任意多人**，同一文件可重复使用（没有「链接过期」这回事）。
- 每名被试做完后自己截图发回，你逐份收。

---

## 二、被试：会看到什么

| 阶段 | 画面 | 说明 |
|---|---|---|
| ① 开始页 | 深色页面，含**设备/环境提示 + 知情同意 + WebGL 检测** | 明确告知：匿名、自愿、可随时退出 |
| ② 点击「▶ 点击开始」 | 进入**全屏**并开始实验 | 这一步的点击同时满足浏览器的"用户手势"要求（全屏、音频都依赖它） |
| ③ 实验过程 | 与本地 PsychoPy 一致的刺激与按键/鼠标反应 | 中途**不要刷新或关闭页面** |
| ④ 结果页 | 摘要（被试编号 / 行数 / 字段数）+ **下载 CSV** + **数据二维码** | 三选一即可回传 |

**数据在哪**：全部留在被试自己的电脑上（内存 + 浏览器本地存储）。psyweb **不上传任何数据**。

---

## 三、主试：怎么把数据收回来

打开 `collector.html`（双击即可，纯本地）：

1. 把被试发来的二维码截图**拖进页面**（或直接 `Ctrl+V` 粘贴、或点击选择文件）。
2. 页面自动解码 → 显示「分片识别」：数据集编号 + `n/n 张 完整`。
   - 显示「缺 2」= 被试少发了第 2 张，让对方补发即可。
   - 一次可以把**多名被试**的截图全拖进来，程序按数据集自动分组，不会混。
3. 完整的数据集点「**入库**」→ 出现在下方表格（被试编号 / 行数 / 列数）。
4. 全部收完后点「**导出合并 CSV**」→ 得到一个含所有被试的总表，直接进 SPSS / R / Python。
   - 也可以逐人「下载」单独文件。

## 四、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 双击后白屏、什么都没有 | 浏览器过旧。请用较新的 **Chrome / Edge**（本实验需要 WebGL） |
| 开始页显示「未检测到 WebGL」且按钮变灰 | 同上；换浏览器，或确认没有禁用硬件加速 |
| 点击开始后没进全屏 | 浏览器拒绝了全屏请求（不影响实验），可手动按 `F11` |
| 实验中按键没反应 | 先点一下页面任意处让窗口获得焦点；确认用的是电脑键盘 |
| 中途误关页面 | 数据每 5 秒自动存到浏览器本地。**重新打开同一个文件**，开始页会提示「检测到上次未完成的数据」并提供下载 |
| 被试只发了 1 张二维码 | 正常流程需要发**全部**（结果页写着共几张）；让对方补发 |
| 二维码扫不出来 | 让对方在微信里**勾选原图**重发；或让对方改用「下载数据文件」发 CSV |
| 想改知情同意文字 / 实验标题 | 在打包时用参数指定标题（`--title "选择实验"`）；同意书文案改 `src/psyweb-shim-2026.js` 里的开始页段落 |

## 五、重新打包（改了实验之后）

```powershell
# 1) 用 PsychoPy Builder 重新导出 HTML（会生成 xxx.js / xxx-legacy-browsers.js）
# 2) 打成单文件便携包
node src/pack-portable.js --dir <实验目录> --js <实验目录>\xxx-legacy-browsers.js `
     --out 输出\portable_xxx.html --title "实验名称" --expname "实验名称"
```

打包器会：修复自动翻译缺陷 → 内联运行时与资源 → 装开始页/资源门禁/数据出口 → **逐条自检**（任一补丁没打上就拒绝出包）。

## 六、边界（请如实告知合作者）

- **计时精度**：浏览器 `requestAnimationFrame` + `performance.now()`，跨设备抖动通常在 5–20 ms 量级，**不能与实验室光电管/EEG 触发相比**。需要毫秒级严格对齐的范式不要搬上网。
- **硬件**：脑电、眼动、串口/并口触发、按钮盒——在线一律不可用。
- **设备差异**：屏幕尺寸、刷新率、操作系统都会被记录在数据里（`frameRate` / `OS` 等列），分析时应检查。
- **伦理**：知情同意书是模板；**伦理审查、数据保管责任由研究者本人承担**，工具不代劳。
