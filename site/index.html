psyweb 在线打包

把 PsychoPy 实验变成 一个 html 文件：被试双击即测，测完用截图或 CSV 把数据发回来。
全部在你的浏览器里完成——不上传、不联网、没有服务器参与。
⚠️ 先分清两种 HTML —— 它们不是一回事
PsychoPy Builder 导出的 HTML 本工具产出的 HTML
形态 一堆文件：index.html + xxx.js + lib\ + 图片/条件文件 一个 .html 文件
能直接发被试吗 不能
它依赖 Pavlovia 服务器、靠相对路径找运行时库、没有开始页/结果页/数据出口		 能
双击即测；被试做完看到结果页，可截图/下载 CSV/二维码回传
数据去哪 默认上传到 Pavlovia 云端（需要账号与网络） 只留在被试电脑上，由被试发回给你
用途 本页的输入（中间产物） 发给被试的最终产物
离线单文件版（对方网络不稳 / 要脱网使用）
本页需要联网打开。如果你要发给的人网络不稳，或你需要在没有网的电脑上转换， 可以下载离线单文件版：一个约 3 MB 的 html，双击即用，功能与本页完全相同 （运行时素材已内联，不依赖网络，也不需要安装任何东西）。Windows / macOS / Linux 通用。
⬇ 下载离线单文件版（psyweb打包工具.html）
三步
① 在 PsychoPy Builder 里导出：菜单 File → Export HTML…（或往 Pavlovia 同步一次），得到一个含 index.html、xxx.js、lib\、图片与条件文件的文件夹。
② 把那个文件夹整个拖到这里（下面虚线框）。
③ 下载生成的单个 html，发给被试即可。
注：本页不处理 .psyexp —— 把 .psyexp 编译成 .js 的是 PsychoPy 本体（Python 程序）， 它的依赖里有 wx、pyglet 等原生桌面库，浏览器里跑不起来（实测：编译链上有 158 个模块）。 想"直接拖 .psyexp 一步到位"，请用随包的本地工具或免安装分发包 —— 它们在你自己电脑上调用已装的 PsychoPy。
